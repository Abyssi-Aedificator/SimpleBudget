Version 1.0.6
- Fixed: Budget inline edit — pressing Enter now saves the amount and Escape cancels (was broken by a malformed keyboard handler).
- Fixed: Planification no longer double-counts transactions dated later in the viewed month (they appeared as both spent and upcoming).
- Fixed: Tracking view charts now animate independently instead of one cancelling the other's animation.
- Fixed: Debt planned balance was one month ahead of the schedule — now matches the monthly table and payoff estimate.
- Fixed: Transaction edit form no longer allows assigning a regular transaction to an Investment account.
- Fixed: CSV import handles ISO dates and validates day/month ranges instead of silently swapping day and month.
- Fixed: CSV import parses parenthesized negatives and comma decimal separators correctly.
- Fixed: Renaming or deleting a category now updates planification budgets, import rules, and refund links.
- Fixed: Restoring a backup relinks recurring rules before posting, preventing duplicate auto-posted transactions.
- Fixed: Net worth chart now includes opening (initial) account balances.

Version 1.0.5
- Changed: Migrated changelog to standalone changelog.txt file and removed all changelog code from the app (CSS, HTML, sidebar entry, What's New modal, and JavaScript).

Version 1.0.4
- Fixed: Investment Market Value now correctly aggregates shares across multiple accounts holding the same symbol — was picking one snapshot arbitrarily, causing $0.00.
- Fixed: Refresh Prices button no longer permanently locks when no API key is set or no holdings exist.

Version 1.0.3
- Fixed: Planification month dropdown now includes months that have budget entries (was using wrong property `p.month` instead of `p.startMonth`).

- Fixed: Transaction list sort is now deterministic: same-date transactions are ordered by ID instead of flipping on every re-render.
- Changed: Removed 4 unused functions — `dfEstimatePayoff()`, `initialBalanceRowHtml()`, `openCategorySettings()`, `openImportSettings()`.
- Changed: Removed orphaned CSS rules — `.plan-card-editing` duplicated declaration, `header.top`, `.up-cards`, `.top-actions`, `.icon-btn`.

- Fixed: Filter dropdowns — Added null checks to prevent errors when category and account dropdown elements are not yet in the DOM.
